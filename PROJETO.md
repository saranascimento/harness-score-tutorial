# Meeting Cost CLI

Calcula o custo total de mão de obra de uma reunião a partir do número de
participantes, da duração em minutos e do custo por hora.

## Uso

```
npm start -- <participantes> <duracao_em_minutos> <custo_por_hora>
```

Exemplo:

```
npm start -- 5 30 120
```

Saída:

```
Custo total da reunião: R$ 300,00 (5 participantes, 30 min, R$ 120,00/h)
```
